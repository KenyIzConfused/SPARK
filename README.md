# SPARK
A Gamified Sign Language Learning Application for Inclusive Communication among Learners, Parents, Teachers, and Student-Teachers

How can a gamified, mobile-based sign language learning application improve inclusive communication, engagement, and learning outcomes among students at Solano East Central School – Integrated SPED Center, while enhancing collaboration between parents, teachers, and Bachelor of Special Needs Education student-teachers from Saint Mary’s University through accessible, adaptive, and interactive digital tools?
